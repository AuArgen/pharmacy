## 1. Что это за проект

**АптекаРядом** — веб-сайт, который при заходе обычного пользователя определяет его
геолокацию и показывает **ближайшую аптеку** (плюс список других поблизости) с
расстоянием, картой и кнопкой построения маршрута.

Цель: максимально простой UX — пользователь заходит, разрешает геолокацию, мгновенно
видит куда идти.

## 4. Как запустить

```bash
# из папки проекта
cp .env.example .env   # при первом запуске (можно поменять PORT/ADMIN_PASSWORD)
docker compose up --build
# открыть http://localhost:<PORT>   (по умолчанию 8080)
```

Порт, пароль админки и offline-режим геокодирования настраиваются в `.env`:
- `PORT` — порт сайта (по умолчанию 8080)
- `ADMIN_PASSWORD` — пароль входа в `/admin.php` (по умолчанию `admin123`)
- `DISABLE_GEOCODING` — `1` отключает обращение к Nominatim
Узнать активный адрес: `docker compose port app 80`.

База данных создаётся автоматически при первом обращении (`src/lib/db.php`),
демо-аптеки добавляются, если таблица пустая. Файл лежит в `./data/pharmacy.sqlite`
и сохраняется между перезапусками.

> ⚠️ Геолокация в браузере работает на `http://localhost` и на HTTPS.
> На «голом» IP по HTTP браузер геолокацию заблокирует.

### Сброс базы
Удалить файл `./data/pharmacy.sqlite*` и перезапустить контейнер —
демо-данные засеются заново.

### Ошибка `unable to open database file` (права на ./data)
SQLite требует право записи на КАТАЛОГ (для WAL/journal), не только на файл.
При bind-mount `./data:/var/www/data` права хостовой папки перекрывают то, что
задано в Dockerfile. Если папку создал Docker от root — `www-data` (uid 33 в контейнере)
писать не может. Починка на хосте из папки проекта:
```bash
mkdir -p data
sudo chown -R 33:33 data   # 33 = uid www-data внутри контейнера
docker compose up -d
```
`get_db()` теперь сам бросает понятную ошибку (каталог не существует / нет прав /
файл не доступен на запись) вместо криптичного PDOException.

## 5. API

### `GET /api/nearby.php`
Параметры:
- `lat` (float, опц.) — широта пользователя
- `lng` (float, опц.) — долгота пользователя
- `limit` (int, опц., 1–50, по умолчанию 10)

Если переданы валидные `lat`/`lng` — список сортируется по расстоянию и у каждой
аптеки появляются `distance_km` и `distance_text`. Без координат возвращается
несортированный список.

Ответ:
```json
{
  "ok": true,
  "has_location": true,
  "count": 10,
  "pharmacies": [
    {
      "id": 1, "name": "...", "address": "...", "phone": "...",
      "hours": "...", "is_24h": false, "lat": 42.87, "lng": 74.60,
      "distance_km": 0.35, "distance_text": "350 м"
    }
  ]
}
```

### `POST /api/track.php`
Лог визита (вызывается фронтендом через `navigator.sendBeacon` после определения
геолокации, не блокирует UI). Тело JSON:
`{ lat, lng, accuracy, nearest_pharmacy_id, nearest_distance_km }`.
Сервер дополняет запись IP (учёт `X-Forwarded-For`), обратным геокодированием
(страна/регион/город/район через Nominatim OSM) и датой (UTC). Ответ: `{"ok":true}`.

## 6. Схема БД

### Таблица `pharmacies`
| поле     | тип     | описание                          |
|----------|---------|-----------------------------------|
| id       | INTEGER | PK, автоинкремент                 |
| name     | TEXT    | название аптеки                   |
| address  | TEXT    | адрес                             |
| phone    | TEXT    | телефон                           |
| hours    | TEXT    | часы работы (текст)               |
| is_24h   | INTEGER | 1 = круглосуточно                 |
| lat      | REAL    | широта                            |
| lng      | REAL    | долгота                           |

Демо-данные — аптеки г. Бишкек (см. `seed_if_empty()` в `src/lib/db.php`).

### Таблица `visits` (лог визитов для отчётов)
| поле                | тип     | описание                              |
|---------------------|---------|---------------------------------------|
| id                  | INTEGER | PK                                    |
| ip                  | TEXT    | IP клиента                            |
| lat, lng            | REAL    | координаты пользователя               |
| accuracy            | REAL    | точность геолокации (м)               |
| country             | TEXT    | страна (геокодирование)               |
| region              | TEXT    | регион / область                      |
| city                | TEXT    | город                                 |
| district            | TEXT    | район / микрорайон                    |
| nearest_pharmacy_id | INTEGER | id ближайшей аптеки                   |
| nearest_distance_km | REAL    | расстояние до неё                     |
| device_type         | TEXT    | mobile / tablet / desktop             |
| device_os           | TEXT    | ОС (Android/iOS/Windows…)             |
| device_browser      | TEXT    | браузер (Chrome/Safari…)              |
| event               | TEXT    | 'ping' или 'leave' (уход со страницы) |
| user_agent          | TEXT    | полный user-agent                     |
| created_at          | TEXT    | дата/время (UTC, 'Y-m-d H:i:s')       |

Поля устройства определяются на фронте (`detectDevice()` в app.js) и шлются в track.php.
Трекинг идёт **каждые 3 секунды** (watchPosition + setInterval) и **продолжается, когда
вкладка в фоне** (на паузу НЕ ставим). При уходе/закрытии вкладки шлётся финальный лог
`event='leave'` через `pagehide`/`visibilitychange` (sendBeacon успевает уйти).
ВАЖНО: когда вкладка ПОЛНОСТЬЮ закрыта, JS останавливается и периодические пинги
прекращаются — это ограничение браузера; «leave»-лог фиксирует последний момент.

### Таблица `geocode_cache`
Кэш обратного геокодирования по округлённым координатам (`coord_key` = 'lat,lng' до
3 знаков). Нужна, чтобы частые пинги (раз в 3 сек) не дёргали Nominatim повторно.
Используется `reverse_geocode_cached()` в `src/lib/visit.php`.

### Таблица `admin_blocks`
Анти-брутфорс входа в админку: `ip` (PK), `fails`, `blocked_until` (UTC).

## 6a. Админ-панель `/admin.php`
Пароль — переменная окружения `ADMIN_PASSWORD` (по умолчанию `admin123`,
**смените в проде!**). Отчёты: всего визитов / сегодня / уникальные IP, клиенты по
регионам и районам, визиты по дням, типы устройств и браузеры (диаграммы), топ
востребованных аптек, таблица последних 50 визитов. Сессия PHP, выход — `?logout=1`.

**Карта местоположения:** в таблице визитов кнопка «📍 На карте» показывает точку
клиента на Leaflet-карте с кругом точности (радиус = `accuracy`).

**Журнал визитов:** поиск (`q` — по IP, региону/городу/району, устройству, дате),
сортировка (параметры `sort`+`dir`, белый список колонок в `$sortable`) и пагинация
(`page`, по 20 строк). Хелперы `log_url()` и `sort_link()`. Записи `event='leave'`
помечены бейджем «ушёл».

**Блокировка входа:** после ОДНОЙ неудачной попытки IP блокируется на 60 сек
(`$BLOCK_SECONDS` в admin.php). На странице — обратный отсчёт с авто-перезагрузкой.
Верный пароль снимает блокировку. IP берётся через `client_ip()`.

> Обратное геокодирование можно отключить переменной `DISABLE_GEOCODING=1`
> (offline-режим — тогда регион/город не заполняются, но координаты/IP/дата пишутся).
> ⚠️ Трекинг раз в 3 сек создаёт много строк в `visits` — при необходимости
> добавьте очистку старых записей или увеличьте интервал.
